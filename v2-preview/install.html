Install DnBOX

Choose the model printed on the keyboard. A USB or port name is not confirmation. The real installer also checks the connected device and stops if they do not match.

Which keyboard is this?

The nightly manual: “A connection name is not proof of the board model.” The live installer also notes that an Elite on some builds may report a Pro-like USB name — still use the printed name, and let the installer check. If they disagree, the write must not start.

If the device does not start

Which package?

The default is the known-good fallback. A newer candidate is listed only with its limits, and is not selected.

Package version

The original 0.0.26 at 600b3b45 was withdrawn after reports of updates stuck at Restarting and very long or failed startup. It is not offered. If that package is already on a device, restore stock — do not reinstall it.

Confirm you have read the limits

0.0.26 at 94197fc8 is not recommended as a stable release. Physical startup is not verified. To use it in this prototype, confirm that you have read that.

Which path are you on?

Both of these are supported. They are equal choices, not a preferred path and a fallback.

How are you installing?

Back up sample slots first

The nightly and production READMEs both say this. The nightly manual: before changing firmware, save important samples and export songs, and keep the exported files. An install that would lose loops may save and restore them, but a backup of your own is still the safe option (production README, FAQ).

Look at the name printed on the case. Choose the Elite or Pro package that matches that name, and let the installer check the connected device again.

If the device does not start

The USB connection was lost

Write stopped This page cannot tell, from a still screen, whether the keyboard will start on its own after a stopped write.

Replug the same USB cable. Keep it connected. Finish the same package from update mode. A dark display can be normal — do not switch the device off. Do not install a different package to “rescue” a half-write.

Full recovery notes

The write stopped before it finished

Write stopped This page cannot tell whether the keyboard will start on its own.

Replug, if needed, and finish the same package. Do not switch packages mid-repair. If the screen stays black, go to recovery: restore M-VAVE stock for this model, and keep the activity log, the package version, and the exact model.

Full recovery notes

The screen stayed dark, or Restarting did not end

Start not confirmed This is not a successful install.

Retain the activity log, the selected package version, and the exact model. Restore M-VAVE stock firmware with the installer, or with M-UPGRADE and the stock package for this model. Do not use another device’s stock firmware. Do not reinstall withdrawn 0.0.26 at 600b3b45.
