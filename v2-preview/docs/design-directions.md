The 909 LCD image is a real DnBOX emulator capture, expressly labelled not hardware. In the standalone [installer simulation](../install.html): browser permission and errors are distinct; a failed slot backup is **warning only**, never a mandatory gate (source decision c237b0d1); firmware transfer, restart observation, and boot observation are separate. Existing-slot preset overwrite has its own backup-first requirement. No Web MIDI, WebUSB, serial, network calls, device writes or emulation are implemented in these previews.

Admin verification is owned by #883/RP2, not this design branch; a real browser firmware emulator is separately EM1. Neither is duplicated. Live site root, live installer, catalogs, packages, firmware, admin backend and device remain untouched. **Owner mockup review is required before design publication.**
