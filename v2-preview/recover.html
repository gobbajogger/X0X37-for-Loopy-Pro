Read this before you start a write, not only after one fails. This page is a guide. It cannot see your keyboard.

If the keyboard will not start

Keep the USB cable connected until any write already in progress has finished. Do not unplug mid-write. A dark display during a write can be normal — do not switch the device off to “fix” it.

The nightly SMK manual says to retain the activity log, the selected package version, and the exact model, and to report them. It also says: do not use another device’s stock firmware or recovery instructions, and do not treat the FM-1 recovery procedure as an SMK procedure.

  • A write is still running, or the display went dark during a write Leave it. Keep USB connected. A dark display during a write can be normal. Do not power-cycle. When the installer can talk again, finish the same package.
  • The write stopped, or the USB cable came out This page cannot tell, from a still screen, whether the keyboard will start on its own. Replug the same cable. Open the installer and finish the same package from update mode. Do not switch to a different package to “rescue” a half-write.
  • The connected device did not match the package Nothing should have been written. Look at the name printed on the case — a USB or port name is not confirmation. Choose the Elite or Pro package that matches, and let the installer check the connected device again.
  • The screen stays black, or Restarting does not end, after a write Retain the activity log, the package version, and the exact model. Use the installer to restore M-VAVE stock firmware, or use M-VAVE M-UPGRADE with the stock package for this model. Report those three facts. Do not use a stock file for a different keyboard.
  • Original 0.0.26 (600b3b45) is already on the device That package was withdrawn after reports of updates stuck at Restarting and very long or failed startup. Do not reinstall it. Restore stock firmware, then, if you install again, use 0.0.25.1, the known-good fallback.
  • I only wanted the factory software back The installer can restore M-VAVE stock firmware. M-UPGRADE, from M-VAVE’s download page, does the same. Use the stock package for the model printed on the case.

What this page will not tell you to do

It will not give you the FM-1 rescue script from the production manual’s section 17. The nightly SMK manual is explicit: do not treat that procedure as an SMK procedure. It will not tell you to install another device’s stock firmware. It will not tell you that the keyboard will start, after a stopped write, because this page cannot know that.
