Presets

Device send blocked The DNPR research document (introduction, R3, §5) says device wiring of the codec is blocked on Optimizer flash savings (+2,164 B; floor 8,192 B). This page must not claim a live device send until the firmware link exists and the flash floor holds. It can already open, check, and save .dnpr files on the host. This prototype simulates that librarian. It does not run the codec, and it contains no Web MIDI code.
