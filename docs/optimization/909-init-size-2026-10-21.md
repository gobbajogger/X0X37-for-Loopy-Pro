# Optional 909 initialization code-size change

Receiver: the assigned reference-SMC integrator, via the coordinating task.
This is an optional source change, not a firmware release, installation or SMC fix.
Base: `2695701fe9ae63dbb6f1f76d4dc11ebbf39da834`.
Measured source: `06e9424e42780ecb8a796266e1adb1ff8bafd4d6`.

## Change

A single noinline wrapper shares the eleven textual biquad coefficient setup
sites in 909 initialization. The coefficient implementation, constants and
initialization order are unchanged. Parameter changes, triggers and render paths
still use their original implementation. No samples, features, guards, Bluetooth
or security behavior are removed. The study overlay explicitly includes drum909.c
so the measured candidate actually contains this change.

## Checks

- Host Clang 19.1.7 at `-O2 -ffp-contract=off`: exact normalized initial-state
  fingerprint and all 264 rendered-audio fingerprints matched the original.
  Covers eleven voices, six velocities, four parameter profiles, 131072 frames
  per case, including retrigger at frame 32768; 34,603,008 frames total.
- Candidate run under GCC AddressSanitizer and UndefinedBehaviorSanitizer passed
  the same cases (`ASAN_OPTIONS=detect_leaks=0`).
- All fourteen pre-existing target function sections other than drum909_init
  are byte-identical and have identical symbolic relocation targets/addends.
  This includes setter, trigger, renderer and render wrappers.
- Existing target guards passed: code/RAM/pool limits, no soft-double routines,
  register-access scope and RAM-text no-call check.
- `git diff --check` passed.

No donor-reference suite rerun: the 9W9 checkout was not present. This is a
baseline-differential test, not independent validation of the original circuit.
No hardware render, RF test, on-target initialization-state measurement or boot
time measurement was performed. Audio fingerprints use FNV-1a, not formal proof.
The generated app is NON-INSTALLABLE; normal integrator review and exact candidate
validation remain required. Do not flash this study output.

## Other candidates considered

- Applying the existing minsize attribute only to drum909_init increased the
  exact application by 112 bytes. Rejected; not included.
- Outlining shared render/trigger coefficient paths was not pursued: it would
  add real-time call overhead and require a larger timing review.
- Sample compression/capacity and pool buffers belong to separate lanes; no
  changes were made here. Font assets and pot lookup tables were left untouched.
