# Исправление допуска загрузки NIGHTLY

Исходники объединяют PR #7/#6 и каталог/тесты PR #3 R25 (117 записей истории).
Download выдаёт только Blob после проверки размера, SHA-256 и точной модели.
Отозванные, неподтверждённые и устаревшие асинхронные результаты не допускаются
к загрузке или установке. Обе кнопки установки используют общий запрет повторного
запуска до запроса MIDI. Ошибка разрешения, контроллера или прерывание допускают
повторную попытку. Сведения о происхождении GPL сохранены.

Проверки: `npm run build`, `npm test`, `npm run test:browser`. Chromium проверяет
полную страницу с синтетическими данными и имитацией MIDI, размеры 320/390/1280,
EN/JA, Elite/Pro. Это не проверка устройства или настоящего пакета прошивки.
Подробные команды, ограничения и журнал — в английском документе и
`docs/repair-evidence/`.

Следующий этап: независимая проверка точного SHA, затем единственный ответственный
за слияние сайта. Публикация остаётся у единственного Pages publisher. Каталог
устанавливаемых прошивок пуст: реальные пакеты, контроллеры, безопасность OTA,
лицензии и HTTP-проверки остаются отдельными обязательными этапами. Защищённые
ветки, прошивка, планировщики и устройства не изменены. Родительский поток
координирует следующий этап без создания конкурирующих исполнителей.

В R2 исправлены замечания независимой проверки: отмена Download выполняется до
чтения повреждённых метаданных, прежний Blob отзывается; длинные строки истории
переносятся без удаления 117 записей. Chromium: 208/208, повтор исходного набора
независимой проверки: 82/82. Подробности и журналы — `repair-evidence/r2/`.
PR остаётся черновиком до повторного независимого заключения.

R3 исправляет новые замечания F3/F4 к HTTP-ответу истории: схема, статусы и поля
проверяются до показа; обе секции создаются вне DOM, ошибка очищает их полностью.
Данные 117 записей и исправления установщика не изменены. PR снова черновик;
повторная независимая проверка обязательна. Журналы: `repair-evidence/r3/`.
