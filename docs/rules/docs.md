# Rules v3: docs, checklists and logs

Read when: before you write an owner test checklist, a doc or a log, and before you log a device result. Read it also at the end of each task.

### Rule 12 [v2: 15, v2: 11 sentence 1, and the NEW checklist header]
Step: P7 checklist, P11 log result.
Rule owner: Docs Keeper.

Do not invent data. Docs and logs hold only development information. Update BEHAVIOR.md (reference copy on integration), ROADMAP.md, USER_PREFERENCES.md and the log in the same task. Log a device PASS only for the items and build that the owner names, and mark the others NOT TESTED.

NEW: Start each owner test checklist with three header lines. The "Build" line gives the batch number and the gated hash. The "Replaces" line gives the earlier checklist that this checklist replaces, or "none". The "Checked against decisions" line gives the time of the latest USER_PREFERENCES.md entry that you compared with the checklist.
