# Rules v3: owner messages and decisions

Read when: before you write to the owner or relay an owner report, and before you send a decision message or a skill change.

### Rule 13 [v2: 2, sentences 1 to 4]
Step: P8 owner notice, P10 owner test, each message to the owner.
Rule owner: Orchestrator.

Write each message to the owner in ASD-STE100, with plain words about what the owner hears, feels and does. Describe a change to the owner only after you verify it. Orchestrator is the only route for questions to the owner. If an agent quotes an owner report with the build, the report is valid in any chat.

Make each message to the owner as short as possible, and keep every fact (caveman length). Use full, simple ASD-STE100 words. Do not use shorthand, IDs or hashes, unless the owner needs them. [owner 2026-10-17 00:05]

### Rule 14 [v2: 3, and v2: 2 sentence 5]
Step: P2 to P5 (before you decide a change).
Rule owner: Orchestrator.

Ask the owner only about a change that the owner can see, hear or play. Ask before you make the change. This includes each change that affects how the keyboard plays. Decide all other changes and continue.

### Rule 4B [v2: 14, sentences 3 to 5]
Step: each decision and each skill change.
Rule owner: Orchestrator.

Send skill changes through Orchestrator. Send one decision message for each item. Give it a tag "supersedes <time>" when it replaces an earlier decision.
