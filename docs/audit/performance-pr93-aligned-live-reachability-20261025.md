# R24: Verify aligned-checkpoint fast exit on the real BREAK live path (2026-10-25)

**Musician-facing reason.** Reversed BREAK slices must keep the same sound, NoteOff, pad switching, and STOP behavior. R23 reported a narrower 6–10% host microbenchmark reduction for an ADPCM seek helper. A helper-only benchmark does not prove its new branch is reached while live audio is rendered, nor does it measure on-device latency.

**Design.** This test compares the exact R22 parent BREAK source with the R23 production source on the existing deterministic live two-voice reverse-crossfade workload. All consumed C sources, headers, existing fixture, and R22 runner are pinned by Git blob SHA before execution. It instruments disposable compiler copies only: one counter is incremented solely inside R23's new aligned-checkpoint early exit. The tracked firmware implementation and controller are unchanged.

**Exact tested inputs.** PR #93 parent HEAD `173b8a5c713a57976926932047591dd8d2565e4d`; complete tree `1a80736d85f5fd72264049b59b73a2cc2c6f43c2`; unchanged R23 compiled `firmware/` tree `75723d43185b1b7aeeaf4c50615e4381ce623a6c`. Before `breaks.c` blob `9e1e607e2ddc3028383bfb6ebc85fbc7ac6864c5`; after blob `01e0e759d2b8be3b028e0e25d4f93348a36aeb46`. Existing R22 native runner blob `4a285e80482c266abc4ac818b4b0ff0910a4930c`.

**Real-path test stimulus.** Three long sample lengths (705600, 1411200 and 2116800), four rates (2, 4, 8, 12), forward and reverse, steady and held-pad switch trials: 48 workloads and 3,840 real 64-frame callbacks per executable. Four GCC/Clang `-O2` executables completed, covering before and after. Each of the four malformed-argument controls returned exit 2. A deliberately mutated source byte was rejected before an evidence directory could be created (exit 1). All compared outputs remained audible until STOP, then silent; PCM, decoded call counts, per-callback maximum/p95/p99, control and overlap results were identical before and after.

**Verified observation.** Both compilers produced identical PCM SHA-256 `b176bc84b11fad61010d715bc30d0ec5235953e0bc916290ba49630e95497cf7`. The exact new branch was hit **147 times per compiler**, including hits in **all 12 live reverse-overlap scenarios**. It was hit in all 24 reverse scenarios and zero forward scenarios; 123 hits occurred in live pad-switch trials, 24 in steady reverse trials. This establishes actual code-path reachability with stable PCM, **not reduced whole-renderer callback time**. Decoder invocation counts should not drop: this optimization removes branch bookkeeping on zero-decode checkpoint seeks.

R24 changes tests and evidence only, so it does not invalidate R23's compiled firmware tree; R23's changed compiled input still requires target BUILD_ONLY and independent QA. The experiment does not change firmware settings, memory, protected branches, firmware packages, Pages, or physical devices.
