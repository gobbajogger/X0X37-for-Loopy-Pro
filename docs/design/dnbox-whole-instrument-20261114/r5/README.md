## What changed, and what already existed

Current dynamic engine labels, fast page topology, native Chicago ADSR, the shallow material, musical pattern picture and performance glyphs are retained baseline. Their restoration in a prototype is not a firmware feature addition. New recognizable drum pictures replace track abbreviations. Juno retains its large numeric values, labels, bars and ADSR control row; proposed shared-family thumbnails occupy only unused row-heading space. The earlier small-value/full-row substitution was rejected during native comparison. Power uses the same top-right position on owned pages and overlays, with bars/USB/unknown; no percentage or charging state is invented.

Drum controls have explicit kit/voice/local-ID owners and native units, including MORE/KIT/mixer aliases. MIX existing-hit deletion waits for a short release; an800ms hold preserves the hit. Empty Song usedP1 stays dim. Chicago WAVE uses final29×19 one-cycle drawing instructions exported through the actual source projector for a bounded edited fixture, replacing the synthetic q-only sketch. Restricted numerical source, factory/native snapshots and executable inputs remain private.
