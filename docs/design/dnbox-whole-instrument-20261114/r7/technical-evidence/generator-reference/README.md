# Public generator mathematics reference

The unchanged public generator C and its four-file dependency closure are pinned to source3c41 in SOURCE-INPUT-MANIFEST.json. This analytical host exporter uses no firmware SDK, audio engine or emulator package. Its generated outputs are supplied as ../generator-reference-fixtures.json. The132 JavaScript checks compare all64 raw/effective step fields, RNG streams, seeds and binary32 boundaries. This is mathematics evidence, not audio or native runtime acceptance.

Reproduce from this directory with `cc -std=c99 -O2 -fno-fast-math -ffp-contract=off -fexcess-precision=standard -Wall -Wextra -Werror reference.c -o /tmp/dnbox-public-gen-reference`, then `/tmp/dnbox-public-gen-reference /tmp/dnbox-generator-fixtures.json`. The compiled host executable is not distributed.

The source preserves GPL-3.0-only notices. NEW clears all64 cells before generating active positions. MUTATE visits the active length and may produce no delta. All-rest input has no forced anchor but can receive randomly created notes at positive density. Raw velocity0 resolves to100. Entropy/time, UI history grouping/capacity and audio are separate contracts.
