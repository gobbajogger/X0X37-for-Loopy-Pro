# Source reuse and distribution scope

The renderer adapts public DnBOX UI families from ui.c, ui_original_controls.h, ui_original_wave.h and ui_pictograms.h at the pinned3c41/d158 inputs. The sources carry GPL-3.0-only. Original historical attributions remain; the firmware UI uses Felucca canvas and panel source credits Leo Kuroshita (@kurogedelic), Hugelton Instruments.

The R7 generator mathematics ports public tb3po.c and uses the exact four-file public dependency closure included under technical-evidence/generator-reference/source. Original source bytes/notices are retained. The supplied C exporter and reference fixtures are analytical evidence, not firmware/audio. Generated NEW/MUTATE outputs contain authored test patterns, not factory/native state exports.

Barlow Semi Condensed Medium/SemiBold/Bold retain the SIL Open Font License in Barlow-OFL.txt.

Miami lookup/drawing and bounded Chicago WAVE coordinates contain final graphical UI outputs. No protected raw factory/native fields, restricted numerical headers, firmware/controller/WASM payload, proprietary SDK/toolchain, private archive, host executable or user secret is included. Actual LCD PNGs and sanitized authored/model receipts remain separate from their private runnable inputs.
