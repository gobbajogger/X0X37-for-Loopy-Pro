## Rules for updating
1. Every PR open, merge or close, and every status change, updates the matching row in the same PR or right after it.
2. A new feature gets a row before work starts. Superseded PRs move to "Other copies"; never delete a row (use **dropped**).
3. A feature is **never "missing"** until you have checked: this registry, all branches (`wip/*`, `lane/*`, `backup/*`, `fix/*`, `feat/*`, `chat/*`, `docs/*`, `codex/*`, `cursor/*`), all closed and merged PRs (`gh pr list --state all --limit 400`), and the ChatGPT Orchestrator.
4. "Hardware-verified" is "yes" only with a linked device test on the same bytes.
