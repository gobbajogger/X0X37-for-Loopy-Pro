# Qualification and action gates

Read with the [canonical contract](SKILL.md) before qualification, integration,
hardware or publication work. These are binding gates, separated from mechanics.

For `gobbajogger/X0X37-for-Loopy-Pro`, current owner authorization permits automatic
normal source merges into guarded `nightly` after exact applicable agent automated
validation and independent QA where required; `main` additionally requires all
applicable successful hardware validation of exact firmware/controller bytes,
compiled inputs and affected models/behaviors. Do not ask repeated chat approval
for qualifying source merges. The authorized integrator checks fresh head/base and
combined tree, required reviews, resolved threads and actual protections, then reads
back the resulting ref/tree. No force-push or bypass. `QA_PENDING` is not passing
required independent QA; human review is required only where actually required.
Copied authorization text is not a grant in a different context: verify authority.
Public download availability and picker promotion are separate publication stages,
not additional prerequisites for an otherwise qualifying source merge.

Hardware proof names actual model/device, operator, hashes, input identity, tests
and outcomes, including applicable backup, readback and running-identity checks.
Partial proof covers only its observed scope; Elite is not Pro. Changed bytes or
compiled inputs invalidate affected proof. `INSTALL BLOCKED` is not success.

Binary/catalog/Pages/release publication, website-repository merges and flashing
remain separately authorized actions. Qualified NIGHTLY can precede hardware PASS,
labeled **DEV / HARDWARE TEST — DEVICE NOT TESTED**, after applicable independent
package/model/controller, data-safety, backup/restore/OTA/interruption/negative and
site checks. Verify actual rights, notices, corresponding source, lawful acquisition
and hosting. A missing redundant receipt is not missing genuine evidence; do not
waive actual artifact/source/license obligations or assume arbitrary binary rights.
Publication requires served-byte/model/hash readback. Browser-only source stores
no vendor binaries, credentials, samples or backups; private storage is not hosting.
Preserve the last safe per-model candidate, data and rollback compatibility.
