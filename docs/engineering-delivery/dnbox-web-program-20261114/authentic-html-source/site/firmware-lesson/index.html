What is exact, and what remains uncovered?

The HTML display uses the actual 240×240 LCD colours and glyph coverage. Its header, rows, cells and four parameter regions follow pinned firmware geometry. Only the qualified 909/BD layout has semantic grid labels and four-kick checks. Actual captured drum-row signatures also allow safe return to BD; positively matched SAVED and SAVES WHEN STOPPED messages have text equivalents. Other messages stay unconfirmed. A different part, page, overlay or mode removes stale step labels. Other layouts are an exact live HTML pixel fallback, not a finished semantic rebuild.

No 0.0.26 behaviour, new firmware design, hardware acceptance or realtime audio qualification is implied. The initial published package has no populated BREAK sample pack. The original emulator source remains owned by PR #899.
