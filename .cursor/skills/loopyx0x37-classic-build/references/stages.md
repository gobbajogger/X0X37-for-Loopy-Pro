# Stage evidence and existing owners

Apply the current [project workflow](../../../../docs/rules/workflow.md) and target
repository rules. A stage is an evidence boundary, not a new-thread requirement.
Reuse applicable current standing authority; do not require its repetition in
this run. Preserve the existing sole source, integration and publication owners.
An assignment to another role is not this worker's permission to take its scope.

| Stage | Required observation |
| --- | --- |
| Source delivery | Scoped nonsecret change, applicable producer checks, exact remote head/tree/changed-byte readback and requested PR. |
| Independent QA | Reviewer who did not author the change checks the exact candidate and meaningful negative/regression paths; required human review remains separate. |
| BUILD_ONLY | Actual pinned native compiler output, source/tool inputs, target model/config, package/controller hashes and budgets. It is not qualified installability. |
| DEV CHECKED | The applicable real development-validation record passes for the exact artifacts; missing or failing required checks stay pending. |
| Integration | Existing assigned owner, current action authority, fresh expected head/base, required reviews/checks and applicable combined-tree proof; resulting remote ref read back. |
| Qualified NIGHTLY | All applicable native, model/controller/integrity/budget, host, installer-negative, backup/readback/rollback, independent QA and lawful-distribution requirements pass. |
| Published/owner-available | Assigned publisher uses its authorized nonforced route; served page, catalog and immutable download bytes match the qualified identities. |
| Device/production | Attributable owner-operated same-byte, matching-model physical proof and separate current action authority. |

Independent QA and builds may proceed on one immutable candidate in separate
worktrees; disjoint implementation need not wait. Only true dependencies block.
Docs, skills and browser-only changes do not require a firmware build.

Firmware development integrates to `gobbajogger/X0X37-for-Loopy-Pro` `nightly`.
Production `main`, production Pages and the separate NIGHTLY browser/status repo
remain distinct destinations. Read each current rule set and actual catalog before
publication. Standing NIGHTLY DEV test-candidate authority needs no per-candidate
chat reply or prior hardware PASS; it does not transfer the publisher's ownership.
Missing optional receipt paperwork does not waive actual checks or redistribution
rights. Do not relabel a dev identity, failed gate or unrun build to pass admission.

No agent gains device-write permission from this skill. Current Elite recovery and
flash remain withdrawn; read-only Pro investigation is not installation. Production
requires the same exact firmware/controller bytes and affected-model hardware proof
plus separate promotion authority. Preserve source notices, private inputs and data.

The old export's forced publisher and generic automatic merger descriptions are
retired. Inspect actual scripts before using them; never force push, bypass a
denial or weaken protections. Source delivery, merged source, served bytes and
device results remain separate even when the same job performs several stages.
