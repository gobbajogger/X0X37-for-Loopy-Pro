# Security

If you find a vulnerability in DnBOX / X0X37 firmware, the installer, or this repository, please **do not** open a public GitHub issue or discussion.

Report it privately with [GitHub's security advisory form](https://github.com/gobbajogger/X0X37-for-Loopy-Pro/security/advisories/new) if that is available to you, and include:

- the affected model and firmware version, if you know it
- a clear description of the issue and how to reproduce it
- whether any user data or a device write is involved

We will aim to reply and to fix confirmed issues before any public disclosure.

Installing third-party firmware is at your own risk. Back up sample slots before you install, and use the official [M-VAVE](https://www.m-vave.com/download) tools if you need to return to stock firmware.
