SMK-37 Elite — защищённый комплект для проверки разработки

Единственный пользовательский файл firmware/x0x-smk37-elite-with-bt.fwsc уже
содержит подходящий Bluetooth-контроллер. Ничего собирать вручную не нужно.
Используйте Install.command: он сохраняет штатные проверки модели, очереди,
границ загрузчика, блокировку устройства, подтверждение, резервную копию и
проверку чтением. Не используйте прямую запись, --force или --no-ctl.

Сначала выполните `bash Install.command --verify-only`: эта команда не открывает
MIDI и не устанавливает зависимости. Исходные файлы сборки, контроллер, запись
DEV и журналы сохранены без изменений в evidence/validated-build/. Объединённый
файл получен из них; исходная запись не подменяется. Коммиты прошивки и средств
упаковки указаны отдельно в MANIFEST.json. Ограничения см. в BUILD_REPORT.txt.

Для разрешённой установки нужен обычный терминал Mac, Git и Python 3.9+ с venv/pip.
Для отсутствующих mido/python-rtmidi может понадобиться сеть. CoreMIDI выбирается
только для процессов установщика; системные настройки не меняются. Отключите
другие совместимые с обновлением клавиатуры. Все слоты сохраняются; контроллер
и сохранённые данные проверяются чтением. Сохраните журналы и резервную копию.

Существующая очередь установки обязательна для проверки. Если её нет,
пишется QUEUE NOT CHECKED, а не успешная проверка. Не создавайте пустую
подменную очередь и не пропускайте ожидающие исправления.

После установки автоматически записывается 45-секундная диагностика только
для чтения. Попробуйте нужные органы управления и отдельно запишите время
движений. Счётчики не доказывают движение. DEV и проверка упаковки не доказывают
исправление SMC. Облачные тесты не означают проверку на Mac или устройстве.

Доступная история Git может быть shallow, как указано в манифесте. SDK,
инструменты компиляции и приватные сырые записи не включены. Только Elite DEV;
сборка Pro и release PASS не предоставляются. Лицензии сохранены.
