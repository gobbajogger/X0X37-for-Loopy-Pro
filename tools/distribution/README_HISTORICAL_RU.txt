SMK-37 Elite — новая сборка исторической базы 1.03 / 53d (DEV)

Исходники: 53d5654c9bbaec10b64c55fb60d0e7d857ba8156, выбранные владельцем.
Это не новое исправление SMC и не подтверждение стабильности или подключения.
Старые назначения органов управления и функции сохранены намеренно; поздние
изменения, диагностика 515 и экспериментальный vendor-port сюда не добавлены.

Историческая связь версии и времени установки — не контрольная сумма реально
установленного образа. От сохранённого раннего образа эта сборка отличается
53 байтами приложения в FONT_XS_DATA и байтами контрольных сумм. Остальные
байты приложения совпадают. Контроллер собран заново и побайтно совпадает
с сохранённым историческим контроллером. Это не исходный прошитый файл.

Сначала выполните `bash Install.command --verify-only`: MIDI не открывается,
зависимости не устанавливаются. Для согласованной установки запустите
Install.command в терминале Mac. Нужны Git и Python 3.9+ с venv/pip;
для отсутствующих mido/python-rtmidi может потребоваться интернет.
Используется CoreMIDI; системные настройки не меняются. Отключите другие
совместимые клавиатуры. Не отключайте питание и USB у SMK-37 Elite.

Используйте только защищённый установщик. Сохраняются проверки модели,
исходников, DEV-записи, пары приложения/контроллера, диапазонов записи,
очереди и эталона заголовка, блокировка устройства и подтверждение пользователя.
Все слоты сэмплов/лупов копируются до записи. После неё выполняются штатные
проверки загрузчика, контроллера и обратное чтение данных слотов.
Сохраните резервную копию и журналы. Не используйте force или обход контроллера.
Имеющаяся очередь обязательна; отсутствие очереди означает NOT CHECKED.
Без настоящего эталона заголовка устройства его сравнение тоже NOT CHECKED.
Когда эталон доступен или обязателен, передайте его через --head-ref с абсолютным
путём. Не создавайте вымышленный эталон.
Существующие настройки очереди и эталона заголовка не заменяются.

АВТОМАТИЧЕСКОГО наблюдения или опроса соединения после установки НЕТ.
Установщик завершает работу после обязательных проверок записи и журналов.
Необязательная диагностика запускается отдельно вручную, только по запросу;
она может менять нагрузку. Команда для такого последующего теста приведена
в README_EN.txt. Install.command её автоматически не выполняет.

Единственный пользовательский файл в firmware/ уже содержит нужный Bluetooth-
контроллер. Исходный образ, контроллер, подлинная DEV-запись и журналы сохранены
без изменений в evidence/validated-build/. Объединённый файл — проверенное
обратимое преобразование, а не подмена исходного результата сборки.
Точные исходники прошивки с Git находятся в x0x37/. Отдельные современные
инструменты установки находятся в host-tools/ и не входят в прошивку.
Все версии и хеши указаны в MANIFEST.json. SDK, toolchain, ключи доступа и
личные записи устройств не включены. Лицензии сохранены. Только Elite DEV.

Проверки DEV пройдены в указанном в записи объёме. В облаке не выполнялись
физическая установка, проверка текущего соединения или полный release gate.
Владелец сообщил об отсутствии подключения и на 515, и на откате 816;
эта сборка не доказывает ни причину, ни устранение проблемы.
