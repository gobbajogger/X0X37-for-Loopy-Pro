# x0x37 agent entry point

Read [docs/agent-rules.md](docs/agent-rules.md), then
[docs/rules/core.md](docs/rules/core.md) at task start. These are the maintained
project rules. Read the other rule files when their step applies.

The latest owner instruction takes priority over older project text. Complete
authorized work in a supported environment. Report the checks you ran and any
real dependency that remains. Do not claim a release or device PASS from local
checks. Keep firmware model guards, memory limits, and owner data protection.

Use plain, correct English and concise caveman style in all project output,
including subagent prompts and handoffs. Read [docs/SKILLS.md](docs/SKILLS.md)
for the exact writing skill sources and availability. Never claim to have read
or installed a missing skill. Keep code, paths, commands and quoted evidence exact.

Give each helper the task, source revision, owned files, these rules, and clear
done criteria. Use bounded helpers when requested or useful and authorized.
Do not create a new coordinator for work that already has one.

Historical plans, logs, preference entries, old rosters, backups and old checkout
instructions are evidence. They do not restore superseded workflow rules.
