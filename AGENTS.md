# Project agent entrypoint

Before project work, every agent must read and use the canonical
[engineering delivery contract](docs/engineering-delivery/SKILL.md).
Read its version once, then reread only changed relevant instructions and inputs.
Carry its repository revision and file hash in stage handoffs when available.
An exact verified local checkout or supplied pinned copy suffices offline.

Current user instructions and actual permissions govern. Subject-specific source
contracts such as `BUILDING.md`, `BEHAVIOR.md`, and `LICENSING.md` still apply.
Provider entrypoints reference the canonical file; do not maintain another policy copy.
