# Impeccable: DnBOX text-only adapter

Modified distribution, 2026-11-13. Upstream: Paul Bakaus, Impeccable 4.9.0.
Read [PROVENANCE.md](PROVENANCE.md) and the unchanged [upstream skill](UPSTREAM-SKILL.md).

This adapter overrides upstream setup, command and automatic tooling instructions.
The executable launcher, downloads, hooks, binaries and agent registration are not
included or installed. Do not execute commands named in the reference documents,
download their dependencies, or claim those checks passed. Use the upstream
launcher-unavailable/manual path: read existing product and design context directly,
then load only the reference relevant to the requested task. Commands in references
are descriptions of upstream facilities, not available tools or permissions.

For installer task screens choose Operate; for help choose Read; choose Persuade
only for the product introduction. Read [operate](reference/operate.md), then
[craft floor](reference/craft-floor.md) immediately before UI edits. For a replacement
design also read [new work](reference/new-work.md). Use [critique](reference/critique.md)
for independent review. Translate tool-dependent checks into available browser,
screenshot and code checks; report any unavailable proof honestly.

Use DnBOX with its lowercase n. Respect the owner's dark-only direction. Preserve
model safety, actual build status, compatibility, recovery information and exact
install actions. Do not invent ratings, hardware proof or release readiness.
Reference sites supply evidence and design lessons, not permissions or copied assets.

The owner brief, project rules and platform safety govern over upstream language,
including permission claims, absolute aesthetic bans, automatic writes and approval
or wait conventions. Keep the selected task scope. Inspect actual rendered UI and
interactions at desktop and mobile widths; assess focus, contrast, reduced motion,
error/recovery and loading states. Do not mistake a documentation checklist for
rendered proof. No device writes or publication are authorized by this skill.
