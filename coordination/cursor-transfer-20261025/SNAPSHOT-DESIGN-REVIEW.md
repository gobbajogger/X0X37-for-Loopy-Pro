## Runtime hooks and continuity

`app/engine.c:s_step` is called before sequencer note sink; it currently publishes eng_step then motion_step. `s_bon` subsequently probability-checks and calls synth_note, and `s_boff` calls synth_off. Resolve step snapshot at step boundary before final per-step settings/note dispatch, with defined skipped/rest/muted behavior. Don't apply a snapshot through16 independently droppable engine_set queue entries: cq_put can drop on full. Use one coherent audio-boundary request/copy and changed-value-only synth_set calls.

Current synth backend is `dsp/synth_engine.h`: `synth_set` checks engine/schema/nparams, `synth_note/off` preserve backend dispatch, `synth_idle` distinguishes tail completion from `synth_active` (303 active returns gate). `synth_request/boundary` panics contexts and is for backend switching; never invoke it to apply same-engine snapshot values. Existing `apply_param(T_303)` explicitly uses synth303_key, so it intentionally rejects other-engine parameters: new snapshot records must not relabel303 values as WBL1. Preserve meaningful bank/schema compatibility and legacy303 path.

Required chosen policies before acceptance: later global changes cannot alter locked note's active parameter base; unlocked subsequent notes restore global base; note-off preserves intended release tail ownership; new note/tie/slide ordering deliberately handles snapshot transitions without reinitializing phase/envelope/glide. Existing retained per-knob locks survive whole-snapshot removal. Proposed deterministic policy for implementation review: snapshot supplies complete note base; explicit per-step knob locks overlay it; motion may modify only as expressly selected, never overwrite stored captured bytes; live knob edits create explicit retained override or require explicit unlock. Document this unresolved choice rather than claim existing implementation establishes it. User requirement for frozen selected-note sound may instead require suppressing motion on locked notes; test/design must settle it explicitly.
