## Source and build

Use a capable current executor. A ChatGPT, Work, Cursor or Codex label does not
prove a tool exists, and a stage change needs no additional launcher. Preserve
active ownership and reuse current standing authority. Use [connected source
delivery](../../../docs/connected-git-source-delivery.md) for supported Git transport,
actual error classification and exact remote readback. A tool denial is not a DNS
failure and cannot be bypassed.

Only a required firmware build needs native Linux x86-64 (or the documented
supported container), the exact JieLi compiler, AC79 SDK and consumed DSP/reference
pins. Discover and verify those inputs outside public Git. Read actual build/test
scripts at the pin; no path or old archive is proof of availability. Docs, skills
and browser-only tasks use their relevant checks. Missing setup blocks only its
dependent operation.

Default to development configuration. For affected firmware, build the required
Elite/Pro model(s), verify the matching controller, source/config/tool identity,
SHA-256/CRC, flash/RAM and pool budgets, and record real exits. The documented pool
floor remains at least 8192 bytes; do not weaken a guard to obtain PASS. A plain
compile is BUILD_ONLY until the applicable qualification passes. Release config
or a full release gate needs the current explicit release-build request.
