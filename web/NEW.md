# What's new

## DnBOX install and data workspace

In the `94197fc8` candidate source, Install, Samples and Projects share one entry page. Manual, What's new and History contain generated content and use the same local Cyrillic/Latin typeface. The published main installer hides and disables its local firmware chooser; the nightly installer has a separate visible local-file section. Availability does not prove a safe stock recovery.

Connection controls distinguish Scanning, Try again and Rescan. Browser support is checked before Connect. Keyboard focus, mobile wrapping, live status and reduced motion are part of the web validation.

Sample preparation follows installation and recovery. It previews the encoded sound, reports storage size and playback rate, and transfers its exact prepared data to Samples. Optional import speed-up reduces stored samples while preserving duration at a lower playback rate.

Archive and connection checks reject malformed backups and stale target sessions. Recovery downloads survive a disconnected project import. Complete and partial sample restoration have different results. Firmware update checks bind the preflight target and saved sample snapshot again before OTA.

These web changes do not change firmware, its project format or the installed package history. At candidate `94197fc8`, Chicago, Miami, Juno and Drone are available; the published 0.0.25.1 release does not include Juno or Drone. The candidate project workspace accepts pattern streams 13–15 with sound revision 13, subject to connected-firmware validation; it does not migrate earlier projects. An atomic snapshot-to-OTA guarantee against other MIDI applications still needs firmware support. Published package and hardware validation states remain separate from these web changes.
