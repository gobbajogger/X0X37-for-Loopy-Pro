Projects

USB MIDI is unavailable here. Use Chrome or Edge over HTTPS or localhost. You can inspect project files without connecting.

DnBOX uses project revision 13 with Chicago and Miami. Earlier projects can be inspected but are not converted or imported into this revision. Keep their original firmware and backups.

Keep a project on your keyboard, start fresh, or take its patterns, sounds and original samples to another X0X.

Connect your keyboard

Connect by USB with X0X running. Stop playback, recording and performance mode before working with projects. Close other editors during transfers.

Not connected

Connect to save, load, reset or export a project. You can inspect a project file before connecting.

On the keyboard

Save stores the live project in the keyboard’s project storage. Load returns to that saved project. Reset starts a default project. These actions keep your uploaded sample slots.

Export a project

Samples retain their original encoded bytes, playback rates and slot order. A project-only file contains sample identities and imports only when every slot already matches.

Import a project

The file is checked before the keyboard is changed.

SlotOn keyboardIn projectAction

Import replaces the live project. The firmware validates it before sample changes, verifies the samples after writing, then adopts the project. Use Save on keyboard to store it immediately; the keyboard’s autosave setting also applies.

The last prepared recovery backup remains available if you close its preview, reconnect or choose another file.

Keep USB connected until the operation finishes. If a sample transfer fails, the page attempts to restore the previous samples and reports the result. The recovery file is also usable after reconnecting.
