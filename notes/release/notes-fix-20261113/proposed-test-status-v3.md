## Test status

**Owner-reported test on an SMK-37 Elite, not a full hardware qualification.** The project owner reported testing 0.0.25.1 and 0.0.26 on an SMK-37 Elite. The installed package hash was not confirmed. The SMK-37 Pro package has not been tested on a device. This report is not a full hardware qualification of either model.

These packages also passed the software checks: the emu360 timing gate (Elite 11,548 µs, Pro 11,564 µs, 0 late, limit 11,609 µs) and the bundled Bluetooth controller check. The emulator result is not a hardware result.
