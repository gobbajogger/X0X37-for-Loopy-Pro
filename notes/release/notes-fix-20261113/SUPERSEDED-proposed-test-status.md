## Test status

**Owner-reported device test.** The project owner reported a device test of 0.0.25.1 on 2026-11-12. The report did not say which board (Elite or Pro) was used. This is a single owner report. It is not a full hardware qualification of either model.

These packages also passed the software checks: the emu360 timing gate (Elite 11,548 µs, Pro 11,564 µs, 0 late, limit 11,609 µs) and the bundled Bluetooth controller check. The emulator result is not a hardware result.
