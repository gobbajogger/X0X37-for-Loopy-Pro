# fm1-live half sampler (BTR, local branch `btr/half-sampler`)

The shared binary `/workspace/emu360-target/release/fm1-live` is **not** modified
or rebuilt. This is a separate worktree of fm1-emu at commit `31157d2`
(same as the live 0.4.0 binary), branch `btr/half-sampler`, built into
`/workspace/btr-dropout-repro/emu-sampler-target` and installed as
`/workspace/btr-dropout-repro/emu-sampler/fm1-live`.

## What changed (emu only, not firmware)

- New module `fm1-soc::half_csv`. After each core-1 slice (the same place
  `core_load::note` already runs), if guest `x0x_dbg.halves` has incremented,
  append one raw CSV row. No averaging.
- Each row: halves, last_us, max_us, late, nested, ui_frames, in_audio,
  audio_xruns, audio_peak_pct, audio_cpu_pct, eng_prof_frames and its delta,
  the 8-element `eng_prof` **delta**, the 5-element `eng_job_cost` (both
  cores, TIMER4, wait subtracted; rise-immediate / slow-fall — stale when
  inactive), `eng_plan` (bit per JB_* on core 1), eng_guard_count,
  perf_cyc_ok, core-1 busy ticks vs `.c1_text`, core-1 ticks spent in
  `run_job` / `c1_take_over`, `c1_job_starts` (entries into `run_job` this
  half), emu_cycles.
- Addresses and field offsets are **not hardcoded**. They are read at
  startup from `FM1_HALF_LAYOUT`, generated by
  `/workspace/btr-dropout-repro/scripts/gen_half_layout.py` from the Elite
  ELF `.symtab` (this ELF has no DWARF) and the 94197fc8 C structs
  (`struct x0x_dbg` all uint32_t, size matches ELF 52; `JB_*` and
  `ENG_PROF` enums).
- Miami's honest per-job cost is `eng_job_cost[JB_A]` (index 2) when 303A
  is Miami, or `[JB_B]` (index 3) when 303B is Miami — not a 0-based index 5.
  The five-element array starts at the ELF symbol `eng_job_cost`.

## Env

```
FM1_HALF_CSV=PATH
FM1_HALF_LAYOUT=/workspace/btr-dropout-repro/emu-sampler/half_layout.txt
```

Use this binary (and its sha256, printed in each run log) for the Elite
core first-pass series. Stock `/workspace/emu360-target/release/fm1-live`
stays untouched.
